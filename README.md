## Or Carmeli 👋

DevOps Engineer focused on Kubernetes and production systems.

I build tools that simulate real-world debugging, based on how systems actually fail in production.

### What I'm building

- **KubeQuest**: interactive Kubernetes learning platform based on real production cases  
- **War Room**: incident investigation simulator with step-by-step debugging scenarios  

### Focus

Kubernetes · Debugging · Observability · Cloud · CI/CD  

### Approach

I focus on understanding how systems behave in failure,
and how to debug them without guesswork.

Most learning platforms focus on how systems should work.  
I focus on what happens when they don't.

### Why I built this

While working with Kubernetes, I noticed a gap:

You can learn concepts, but you rarely practice debugging real failures.

KubeQuest and War Room are built to close that gap,  
by simulating production-like issues and guiding the investigation process.

### Current direction

- Expanding incident scenarios with real-world failure patterns  
- Improving observability signals inside simulations  
- Making debugging flows closer to real SRE workflows
